How this works

This tool reads through your company's information and builds a map of the people, companies, and things it finds, how they're connected, and what's currently true about each one. You can ask a question in plain English and get an answer along with the specific facts it came from.

How does this compare to something like Microsoft Fabric?

Most data platforms, including Fabric, are built to store and report on data that already lives in organized tables. Getting an answer usually means knowing which tables to look in and how they connect to each other.

This tool takes a different approach. It automatically connects related information across your different sources into a single picture, so someone can ask a plain question without needing to know the underlying structure or write a query. It also keeps track of how information changes over time instead of only showing the latest version, and limits what each person sees based on their role, both built directly into how it answers questions rather than something to set up separately.

This is meant to work alongside a platform like Fabric, not replace it. If your data already lives in a Fabric warehouse or lakehouse, this tool can pull from it as a source, the same way it can pull from a regular database.

What's different day to day?
  • You can ask a plain question instead of writing a query or building a report.
  • You get an answer along with the specific facts behind it, so you can check where it came from.
  • If something changed recently, you're told it changed, rather than just given the newest version with no context.
  • What you see is limited to your role, so a sales rep sees their own accounts rather than the whole company's.
How do I read what comes back?
  • Answer: a short response to your question.
  • Where this answer comes from: the individual facts behind that answer, each marked as current or replaced by something newer.
  • The graph: a visual view of what's connected to what. Hovering over something shows more detail.
  • Technical details: the raw data behind an answer, for anyone who wants to look closer.
